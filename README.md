# FoundLab Infrastructure

**Startup Deeptech Brasileira Powered By Google Cloud**

Live Website: [www.foundlab.com.br](https://www.foundlab.com.br)

## 🚀 Sobre o Projeto
Este é o repositório oficial do website da FoundLab Infrastructure. Uma plataforma moderna e de alta performance, desenvolvida para apresentar nossas soluções de infraestrutura cloud e segurança.

## 🛠 Tech Stack
- **Framework:** React 19 + Vite 6
- **Linguagem:** TypeScript
- **Estilização:** Tailwind CSS (Tema Customizado Navy/Gold)
- **Animações:** Framer Motion (v12)
- **Roteamento:** React Router Dom v7
- **Ícones:** Lucide React

## ✨ Funcionalidades
- **Internationalization (i18n):** Suporte nativo para Inglês (EN) e Português (PT-BR).
- **Animações Avançadas:** Interfaces reativas com Framer Motion.
- **Hybrid Routing:** Navegação fluida entre seções da home e páginas estáticas.
- **Design System:** Identidade visual única com paleta de cores corporativa.

## 🏁 Como Executar

### Pré-requisitos
- Node.js (v18 ou superior)
- npm

### Instalação
```bash
npm install
```

### Desenvolvimento
Inicie o servidor de desenvolvimento em `http://localhost:3000`:
```bash
npm run dev
```

### Build de Produção
Para gerar a versão otimizada para produção:
```bash
npm run build
```

## 📂 Estrutura do Projeto
- `components/`: Componentes reutilizáveis e seções da Landing Page.
- `contexts/`: Gerenciamento de estado global (ex: `LanguageContext`).
- `pages/`: Páginas estáticas dedicadas.
- `public/`: Assets estáticos.
